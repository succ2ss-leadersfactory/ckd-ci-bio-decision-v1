# C1바이오 Full Flow Journey 테스트 스크립트

## 1. 목적

이 문서는 `/journey.html` 경로로 추가된 전체 흐름형 실습 Journey 앱을 테스트하기 위한 스크립트입니다.

기존 `/` 앱은 12개 실습 화면이 병렬적으로 구성된 v2 MVP이고, `/journey.html`은 앞선 실습 산출물이 다음 실습에 연결되는 v2.1 후보 화면입니다.

## 2. 접속 경로

```text
https://배포주소.vercel.app/journey.html
```

## 3. 핵심 확인 기준

- [ ] 화면 상단에 `이전 산출물 → 현재 실습 → 다음 연결` 구조가 보인다.
- [ ] Dashboard에서 선택한 팀원이 다음 화면에 유지된다.
- [ ] Dashboard의 Gap 가설이 실행행동 Map에 연결된다.
- [ ] 성과대화 감별의 위험 문장이 1on1 코칭 화면에 연결된다.
- [ ] 고객군 선택이 콜플랜 요청문 화면에 연결된다.
- [ ] 마지막 실행계획 화면에 앞선 산출물 요약이 표시된다.
- [ ] 저장 시 `Google Sheets 저장됨` 또는 localStorage 저장 상태가 표시된다.

## 4. 테스트 순서

### J01 입장과 AI 안전선

1. `/journey.html` 접속
2. 세션코드, 이름, 팀명 입력
3. AI 안전선 확인 저장 클릭
4. `저장하고 다음` 클릭

정상 기준:

- 입력 필드가 정상 표시된다.
- CP 안내 문구가 표시된다.
- 다음 화면으로 이동한다.

### J02 좋은 질문 만들기

1. 나쁜 질문 예시를 확인한다.
2. 안전한 프롬프트를 수정한다.
3. 복사 및 저장 클릭
4. 다음 화면으로 이동

정상 기준:

- 프롬프트 복사가 가능하다.
- 저장 상태가 표시된다.

### J03 Dashboard Reading

1. 팀원 선택
2. 팀원별 지표 확인
3. 고객군 카드 확인
4. Gap 가설 선택
5. 확인 질문 작성
6. Dashboard 판단 저장

정상 기준:

- 선택 팀원이 저장된다.
- Gap 가설과 확인 질문이 저장된다.

### J04 MR별 실행행동 Map

1. 이전 화면에서 선택한 팀원이 표시되는지 확인
2. 연결된 Gap 가설이 표시되는지 확인
3. 확인할 사실, 필요한 행동, 팀장 지원, 2주 행동 약속 입력
4. 실행행동 저장

정상 기준:

- J03에서 선택한 팀원이 그대로 이어진다.
- J03에서 선택한 Gap 가설이 보인다.

### J05 이해관계자 메시지 번역

1. 상사/본부장 메시지 작성
2. 본사 유관부서 메시지 작성
3. 팀원 메시지 작성
4. 동료 팀장 메시지 작성
5. 메시지 저장

정상 기준:

- 앞선 실행행동을 메시지로 번역하는 흐름이 자연스럽다.

### J06 성과대화 AI 답변 감별

1. 자동 생성된 성과대화 프롬프트 확인
2. 프롬프트 복사
3. AI 답변 또는 샘플 답변 붙여넣기
4. 감별 기준 선택
5. 위험 문장 작성
6. 현장 언어 수정문 작성
7. 감별 저장

정상 기준:

- 선택 팀원과 Gap 가설이 프롬프트에 반영된다.
- 위험 문장이 다음 1on1 화면에 연결된다.

### J07 고객관점 콜플랜 요청

1. 고객군 선택
2. 개선된 업무 요청문 작성
3. 콜플랜 저장

정상 기준:

- 고객군 선택값이 저장된다.
- 마지막 실행계획 화면에서 고객군이 요약된다.

### J08 본사 요청 현장 번역

1. 본사 Brief 선택
2. 팀원 실행 요청문 작성
3. 본사 피드백 메시지 작성
4. 현장 번역 저장

정상 기준:

- 본사 요청을 현장 실행언어로 바꾸는 흐름이 보인다.

### J09 MR 1on1 코칭

1. 선택 팀원이 유지되는지 확인
2. 예상 발언 확인
3. 위험 문장이 연결되어 보이는지 확인
4. 대화 시작 문장, 질문, 피해야 할 표현, 1주 행동 약속, 팀장 지원 문장 작성
5. 1on1 저장

정상 기준:

- 선택 팀원과 위험 문장이 연결된다.

### J10 실행계획

1. 앞선 산출물 요약 확인
2. 7일 실행계획 작성
3. 30일 점검 기준 작성
4. 이해관계자 조율 행동 작성
5. 고객 접점 품질 개선 행동 작성
6. AI 활용 팀장 원칙 작성
7. 전체 결과 복사
8. 최종 저장

정상 기준:

- 선택 팀원, Gap 가설, 고객군, 위험 문장이 요약되어 보인다.
- 전체 결과 복사가 가능하다.

## 5. 강사용 확인

참여자 Journey 테스트 후 아래 화면에서 저장 결과를 확인합니다.

```text
/instructor-live.html
```

확인 항목:

- [ ] 세션코드 `C1BIO-1차` 조회
- [ ] 참여자 수 표시
- [ ] 응답 수 표시
- [ ] J01~J10 응답이 Responses에 들어갔는지 확인
- [ ] 최근 응답 상세 확인

## 6. 판정 기준

| 판정 | 기준 |
|---|---|
| 통과 | J01~J10 이동, 저장, 연결 요약, Live Dashboard 조회가 모두 가능 |
| 조건부 통과 | 화면 이동과 저장은 가능하나 일부 연결값이 누락됨 |
| 보완 필요 | Google Sheets 저장 실패 또는 화면 이동 오류 발생 |

## 7. 파일럿 운영 판단

`/journey.html`이 통과되면 교육장에서는 기존 `/`보다 `/journey.html`을 참여자 메인 화면으로 사용하는 것이 더 적합합니다.

다만 첫 파일럿에서는 아래 방식이 안전합니다.

- 강사 주도 운영: `/journey.html`
- 예비 경로: `/`
- 강사용 데이터 확인: `/instructor-live.html`
- 기술 점검: `/?view=check`
