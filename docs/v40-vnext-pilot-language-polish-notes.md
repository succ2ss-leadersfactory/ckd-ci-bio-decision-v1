# v40-vNext 파일럿 화면 언어 교정 메모

내일 파일럿 운영 전, 화면에서 AI가 만든 것처럼 보이는 단어를 현장 말투로 바꾸기 위한 기준입니다.

## 1. 교정 원칙

- 교육생이 화면을 보고 바로 움직일 수 있는 말로 쓴다.
- 보고서 문체보다 회의실과 교육장 말투를 우선한다.
- `산출물`, `프롬프트`, `기반`, `흐름`, `연결`, `구조화` 같은 단어는 꼭 필요한 곳에만 쓴다.
- `우리 조`는 쓰지 않고 `우리 팀`으로 통일한다.
- 파일럿에서는 마지막 실행 메모 단계가 숨겨져 있으므로, 첫 화면에서 `2주 실행 메모 완성`을 과하게 강조하지 않는다.

## 2. 우선 교체할 표현

| 현재 표현 | 파일럿 권장 표현 | 이유 |
|---|---|---|
| 팀장 역할 진행 코치 | 오늘의 진행 안내 | 교육장 안내 말투에 가까움 |
| 현재 영역 | 지금 구간 | 더 짧고 자연스러움 |
| 팀장 역할 진행 상태 | 현재 입력 상태 | 화면에서 실제로 보여주는 내용과 맞음 |
| 이번 단계 코칭 포인트 | 지금 할 일 | 행동 유도력이 높음 |
| 산출물 | 남길 내용 | 교육생이 이해하기 쉬움 |
| 대표 상황 | 오늘 다룰 상황 | 워크숍 언어에 가까움 |
| 역할 확인 | 팀장 역할 이해 | 체크박스 의미가 더 명확함 |
| 미선택 | 아직 선택 전 | 부드러운 표현 |
| 미입력 | 아직 입력 전 | 부드러운 표현 |
| 미완료 | 아직 확인 전 | 압박감이 덜함 |
| 핵심 산출물 | 오늘 남길 내용 | 기계적 용어 제거 |
| 2주 실행 메모 | 실행 기준과 1on1 첫 문장 | 파일럿 11단계 흐름에 맞춤 |
| 팀장 역할 잡기 | 역할 확인하기 | 더 자연스러운 활동명 |
| 팀원 구성 이해 | 팀원 살펴보기 | 교육장 말투에 가까움 |
| 실행 과제화 | 실행할 일로 바꾸기 | 현업 언어에 가까움 |
| 압축 산출물 | 마지막에 남길 기준 | 기계적 느낌 완화 |

## 4. 이미 반영된 표현

`src/journey-shell.tsx`에는 다음 1차 교정이 반영되었습니다.

| 이전 표현 | 변경 표현 |
|---|---|
| AI Leadership Lab Journey | AI 리더십 실습 |
| 자동 저장 | 입력 내용 저장 |
| Step n / 전체 | n / 전체 |
| 진행률 | 진행 |
| 다음 단계 | 다음 |
| 이전 단계 | 이전 |
| 입력 내용은 브라우저에 자동 저장됩니다. | 입력한 내용은 이 브라우저에 저장됩니다. |
| 마지막 단계입니다. 최종 산출물을 확인하세요. | 파일럿 과정의 마지막 화면입니다. 여기까지 정리한 내용을 바탕으로 토의합니다. |

## 5. 브라우저 QA 때 눈으로 확인할 문구

- 첫 화면에서 `2주 실행 메모`가 과하게 보이면 `실행 기준과 1on1 첫 문장`으로 바꾼다.
- 진행 안내 패널에서 `산출물`, `현재 영역`, `진행 상태`가 보이면 각각 `남길 내용`, `지금 구간`, `현재 입력 상태`로 바꾼다.
- 팀원 설명에서 `실행 신호`, `관리 흐름` 같은 표현이 지나치게 반복되면 `움직임`, `일의 흐름`, `대화 포인트`로 바꾼다.
- AI 관련 화면에서 `프롬프트`라는 단어가 너무 자주 보이면 버튼명은 `AI 질문 복사`, 설명문은 `질문`으로 줄인다.
