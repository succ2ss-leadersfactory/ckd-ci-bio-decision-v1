# C1바이오 AI 리더십 Lab 교육장 최종 운영 체크리스트

이 문서는 교육 당일 아침, 강사와 운영자가 20~30분 안에 최종 점검할 수 있도록 만든 운영용 체크리스트입니다.

## 1. 교육 전날 확인

- [ ] Vercel Production URL을 강사와 운영자가 모두 알고 있다.
- [ ] Google Sheets 저장 파일 링크를 강사와 운영자가 알고 있다.
- [ ] Apps Script Web App URL이 `/exec`로 끝나는지 확인했다.
- [ ] Vercel 환경변수 `VITE_GOOGLE_SCRIPT_WEBAPP_URL`이 Production에 등록되어 있다.
- [ ] Vercel 재배포가 완료되었다.
- [ ] `/?view=check`에서 `ping`, `saveParticipant`, `saveResponse` 테스트가 성공했다.
- [ ] Google Sheets의 `Participants`, `Responses`에 테스트 행이 생성되는 것을 확인했다.
- [ ] 테스트 행을 삭제하거나 별도 표시했다.

## 2. 교육장 도착 후 1차 점검

- [ ] 강사용 노트북 전원 연결 완료
- [ ] 강사용 노트북 Wi-Fi 연결 완료
- [ ] 빔프로젝터 또는 대형 모니터 연결 완료
- [ ] 참여자 Wi-Fi 접속 안내 문구 준비
- [ ] Vercel 참여자 앱 `/` 접속 확인
- [ ] 강사용 대시보드 `/?view=instructor` 접속 확인
- [ ] 사전점검 화면 `/?view=check` 접속 확인
- [ ] 브라우저 확대 비율 100~125% 확인
- [ ] 글자 크기와 버튼 크기가 교육장 뒷자리에서도 보이는지 확인

## 3. 사전점검 화면 최종 확인

`/?view=check`에서 아래 순서대로 클릭합니다.

1. `ping`
2. `setupSheetsC1Bio`
3. `saveParticipant`
4. `saveResponse`
5. `getDashboardData`

정상 기준:

- [ ] 모든 항목이 `✅ 성공`으로 표시된다.
- [ ] Google Script URL이 `설정됨`으로 표시된다.
- [ ] Google Sheets에 테스트 참여자와 테스트 응답 행이 추가된다.

실패 시:

- [ ] URL이 `/exec`인지 확인
- [ ] Apps Script 배포 액세스 권한 확인
- [ ] Vercel 환경변수 Production 등록 여부 확인
- [ ] Vercel 재배포 여부 확인

## 4. 참여자 입장 안내

강사 또는 운영자 안내 예시:

> 지금부터 C1바이오 영업팀장 AI 리더십 Development Lab 웹앱에 접속하겠습니다. 오늘 사용하는 모든 데이터는 교육용 가상 데이터입니다. 실제 병원명, 의료진명, 제품명, 매출·처방 정보는 절대 입력하지 않습니다.

참여자 입력값:

- 세션코드: `C1BIO-1차`
- 이름: 본인 이름 또는 교육용 이름
- 팀명: 실습 조 이름

확인 항목:

- [ ] 전체 참여자가 입장 화면에 접속했다.
- [ ] 세션코드 입력 오류자가 없다.
- [ ] 이름과 팀명을 입력했다.
- [ ] `저장하고 다음` 클릭 후 과정 안내 화면으로 넘어갔다.

## 5. 모듈별 운영 체크

### M1 AI 안전선과 질문력

- [ ] AI 안전선 카드가 정상 표시된다.
- [ ] 참여자가 카드 분류를 선택할 수 있다.
- [ ] 강사가 오답률이 높을 만한 항목을 해설했다.
- [ ] 좋은 질문 만들기 화면에서 프롬프트 복사가 된다.

### M2 데이터 기반 성과관리

- [ ] MR 활동·성과 Dashboard가 보인다.
- [ ] 팀원 6명이 성과 이름 + 직급으로 표시된다.
- [ ] 고객군 A~D 카드가 보인다.
- [ ] 핵심 신호와 Gap 가설 입력이 가능하다.

### M3 메시지·성과대화

- [ ] 이해관계자 메시지 작성이 가능하다.
- [ ] 성과대화 프롬프트 복사가 가능하다.
- [ ] AI 답변 붙여넣기 영역이 작동한다.
- [ ] 감별 기준 8개가 보인다.

### M4 업무관리·실행정렬

- [ ] 고객관점 콜플랜 실행 요청문 작성이 가능하다.
- [ ] 본사 요청 → 현장 실행 번역 작성이 가능하다.
- [ ] 고객 공략, 처방 확대 등 위험 표현이 화면에 권장되지 않는다.

### M5 MR 1on1 코칭

- [ ] 페르소나 선택이 가능하다.
- [ ] 1on1 프롬프트 복사가 가능하다.
- [ ] 대화 시작 문장, 코칭 질문, 행동 약속 입력이 가능하다.

### Wrap-up

- [ ] 7일 실행계획 입력 가능
- [ ] 30일 점검 기준 입력 가능
- [ ] 전체 결과 복사 가능
- [ ] 민감정보 입력 여부를 다시 확인하도록 안내했다.

## 6. 강사용 대시보드 운영

- [ ] `/?view=instructor`가 열린다.
- [ ] 응답 화면 수가 표시된다.
- [ ] pendingSync 건수가 표시된다.
- [ ] 참여자 응답 JSON이 보인다.
- [ ] 점수, 등급, 순위 표현이 없다.

강사 활용 방식:

- 안전선 혼동 항목은 즉시 해설한다.
- Dashboard 해석 결과는 토의 질문으로 사용한다.
- AI 위험 문장은 CP 관점 피드백 자료로 사용한다.
- 실행계획은 교육 마무리 공유용으로 사용한다.

## 7. 장애 대응

| 상황 | 우선 조치 | 대체 운영 |
|---|---|---|
| 참여자 앱 접속 불가 | Vercel URL 재확인, Wi-Fi 변경 | 강사 화면 시연 중심 진행 |
| Google Sheets 저장 실패 | `/?view=check` 재확인 | localStorage 모드로 진행 후 결과 복사 |
| 무료 AI 접속 실패 | 다른 AI 도구 접속 안내 | 샘플 답변 Bank 또는 강사 샘플 답변 사용 |
| 일부 참여자 입력값 유실 | 새로고침 전 localStorage 확인 | 메모장에 산출물 복사 후 진행 |
| 대시보드 반영 지연 | 새로고침 | Google Sheets 직접 확인 |

## 9. 종료 멘트 예시

> 오늘 작성한 결과물은 AI가 대신 내려준 정답이 아니라, 여러분이 팀장으로서 데이터를 읽고, 이해관계자를 조율하고, 고객 접점 품질을 높이기 위해 다시 고친 판단의 기록입니다. 현업으로 돌아가실 때는 실제 고객명, 제품명, 내부자료를 AI에 넣지 않는 기준을 반드시 지켜주시기 바랍니다.
