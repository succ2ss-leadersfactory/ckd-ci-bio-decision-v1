## 1. QA 목적

이 체크리스트는 C1바이오 영업팀장 AI 리더십 Lab Journey v39 preview를 실제 브라우저에서 확인하기 위한 운영자용 점검표다.

핵심 확인 관점은 다음이다.

1. 제약 영업팀장 참여자 관점에서 흐름이 자연스러운가?
2. 1단계부터 13단계까지 화면 이동이 끊기지 않는가?
3. 8단계 팀원 7명 실행·코칭 Map이 너무 부담스럽지 않게 안내되는가?
4. 9단계가 우선 1on1 대상과 자연스럽게 연결되는가?
5. 10단계가 새 작성 과제가 아니라 앞 단계 결과를 AI 질문으로 묶는 단계로 보이는가?
6. 12단계가 보고서가 아니라 1페이지 실행 카드로 보이는가?
7. 13단계가 교육생 평가가 아니라 강사용 토의 질문으로 작동하는가?

## 4. 실사용 시나리오 QA

### 시나리오 A. 빠른 완주형

목표: 전체 단계를 빠르게 넘기면서 화면이 깨지지 않는지 확인한다.

1. 1단계에서 팀명과 이름 입력
2. 3단계에서 고민 1개 선택
3. 5단계에서 관리 지표 1개 선택
4. 6단계에서 고객 Data 확인 항목 1개 작성
5. 7단계에서 고객군별 2주 대응 방향 1개 작성
6. 8단계에서 7명 중 2명만 판단 초안 가져오기
7. 우선 1on1 대상 2명 선택
8. 9단계에서 우선 1on1 대상 표시 확인
9. 10단계에서 AI 실행계획 프롬프트 흐름 확인
10. 11단계에서 안전 문장 확인
11. 12단계에서 팀원 7명 요약과 1페이지 안내 확인
12. 13단계에서 강사용 질문 확인

통과 기준: 중간에 빈 화면, 저장 오류, 화면 깨짐이 없어야 한다.

### 시나리오 B. 팀원 7명 집중형

목표: 8·9·12·13단계 팀원 흐름이 제대로 연결되는지 확인한다.

1. 8단계에서 7명 전체 카드가 모두 보이는지 확인
2. 7명 전체에 업무배분 판단만 선택
3. 우선 1on1 대상 2명 선택
4. 3번째 선택 시 제한되는지 확인
5. 선택한 2명의 코칭 목적과 팀장 지원 문장 작성
6. 9단계에서 두 명이 표시되는지 확인
7. 12단계에서 팀원 7명 요약이 표시되는지 확인
8. 13단계에서 업무배분 균형 질문과 우선 1on1 질문이 보이는지 확인

통과 기준: 팀원 7명 전체 조망과 2명 심화 구조가 명확해야 한다.

### 시나리오 C. 복잡도 완화 확인형

목표: 참여자가 “너무 많이 써야 한다”고 느끼지 않도록 안내가 충분한지 확인한다.

1. 8단계에서 “7명 전체는 가볍게” 문구 확인
2. 10단계에서 “새로 쓰지 말고” 문구 확인
3. 12단계에서 “1페이지 실행 카드” 문구 확인
4. 각 단계에서 안내 문구가 너무 길거나 반복적으로 느껴지지 않는지 확인

통과 기준: 안내가 부담을 줄여야 하며, 화면을 더 복잡하게 만들면 안 된다.

## 6. 최종 판정 기준

### 교육장 파일럿 가능

다음 조건을 모두 만족하면 교육장 파일럿 가능으로 본다.

- 1~13단계 이동 중 빈 화면이 없다.
- 8단계 팀원 7명 Map이 모바일/태블릿에서 지나치게 깨지지 않는다.
- 8단계에서 7명 전체+2명 심화 원칙이 명확하다.
- 9단계에서 우선 1on1 대상이 표시된다.
- 10단계가 새 작성 과제가 아니라 자동 조립 단계로 보인다.
- 12단계가 1페이지 실행 카드로 보인다.
- 13단계가 평가 화면이 아니라 강사용 토의 질문 화면으로 보인다.
- 제약영업 안전선 안내가 주요 흐름에서 유지된다.

### 추가 수정 필요

다음 중 하나라도 발생하면 추가 수정이 필요하다.

- 특정 단계에서 화면이 비거나 콘솔 오류가 발생한다.
- 8단계 입력량이 너무 많아 참여자가 진행을 포기할 가능성이 높다.
- 10단계가 다시 작성해야 하는 과제처럼 보인다.
- 12단계 최종 카드가 보고서처럼 길어 보인다.
- 실제 고객명, 병원명, 제품명, 내부 수치 입력을 유도하는 표현이 남아 있다.

## 7. 운영자 메모

현재 v39는 더 많은 기능을 추가하기보다, 실제 교육장에서 참여자가 무리 없이 완주하는지 확인하는 단계다. QA 중 발견되는 이슈는 기능 추가보다 입력량 축소, 안내 문구 정리, 카드 접기/펼치기, 모바일 가독성 개선을 우선한다.
