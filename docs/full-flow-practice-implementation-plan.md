# C1바이오 AI 리더십 Lab 전체 흐름 기반 실습 개발 계획

## 1. 개발 방향 전환

현재 v2는 교육장 파일럿이 가능한 핵심 실습형 MVP입니다. 다음 단계에서는 단순히 화면을 추가하는 방식이 아니라, 교육 전체 흐름에 따라 실습이 자연스럽게 누적되는 구조로 고도화합니다.

핵심 원칙은 다음과 같습니다.

1. 참여자는 먼저 자신의 판단을 입력한다.
2. AI는 정답 생성기가 아니라 판단 확장 도구로 사용한다.
3. AI 답변은 반드시 감별하고 현장 언어로 수정한다.
4. 모든 실습 결과는 다음 실습의 입력값으로 연결된다.
5. 강사용 화면은 평가가 아니라 토의와 운영 지원을 위한 화면으로 설계한다.

## 2. 전체 Learning Flow

```text
입장
→ AI 안전선 이해
→ 좋은 질문 만들기
→ 데이터 읽기
→ 팀원별 실행행동 설계
→ 이해관계자 메시지 번역
→ 성과대화 프롬프트 생성
→ AI 답변 감별
→ 고객관점 콜플랜 실행 요청
→ 본사 요청 현장 번역
→ MR 1on1 코칭
→ 7일/30일 실행계획
→ 강사용 공유와 토의
```

## 3. 전체 흐름별 실습 설계

| 단계 | 화면 | 참여자 행동 | AI 활용 | 산출물 | 다음 단계 연결 |
|---|---|---|---|---|---|
| 1 | 입장 | 세션코드, 이름, 팀명 입력 | 없음 | 참여자 정보 | 전체 저장 키 |
| 2 | 과정 안내 | AI 활용 원칙 확인 | 없음 | 동의 체크 | 안전선 실습 |
| 3 | AI 안전선 카드 | 입력 가능/익명화/금지 판단 | 없음 | 안전선 판단 기록 | 좋은 질문 기준 |
| 4 | 좋은 질문 만들기 | 나쁜 질문을 안전한 프롬프트로 전환 | 프롬프트 복사 | 개선 프롬프트 | Dashboard 질문 품질 |
| 5 | Dashboard Lab | 팀원별 지표와 고객군 신호 해석 | 해석 보조 가능 | 핵심 신호, Gap 가설, 확인 질문 | 실행행동 Map |
| 6 | 실행행동 Map | 팀원별 2주 실행행동 설계 | 데이터 신호 번역 | 확인할 사실, 행동, 지원, 약속 | 성과대화/1on1 |
| 7 | 이해관계자 메시지 | 상사/본사/팀원/동료 메시지 작성 | 메시지 번역 보조 | 대상별 메시지 | 실행정렬 |
| 8 | 성과대화 감별 | AI 답변 붙여넣기, 감별, 수정 | AI 답변 감별 | 위험 문장, 수정 문장 | 1on1 코칭 |
| 9 | 콜플랜 요청문 | 모호한 지시를 실행 요청문으로 전환 | 요청문 개선 | 완료 기준, 점검 질문 | 본사 요청 번역 |
| 10 | 본사 요청 번역 | HQ Brief를 현장 실행안으로 번역 | 현장 실행안 생성 | 팀원 요청문, 본사 피드백 | 실행계획 |
| 11 | 1on1 코칭 | 페르소나별 대화 설계 | 대화 흐름 보조 | 대화문, 질문, 약속 | 실행계획 |
| 12 | 실행계획 | 7일/30일 실행계획 작성 | 필요 시 점검 기준 보완 | 최종 실행계획 | 강사용 공유 |

## 4. v2.1 개발 목표

v2.1은 기존 v2의 실습 콘텐츠를 “전체 흐름형 Journey”로 더 정교하게 연결하는 버전입니다.

### 4.1 참여자 화면 보완

- 화면 상단에 현재 단계의 “이전 산출물 → 현재 실습 → 다음 연결” 안내 추가
- M-P05 Dashboard Lab에서 선택한 팀원이 M-P06, M-P08, M-P11 기본 선택값으로 이어지도록 개선
- M-P05의 Gap 가설이 M-P06 실행행동 Map의 기본 입력 힌트로 연결되도록 개선
- M-P07 이해관계자 메시지 결과가 M-P10 본사 요청 번역과 연결되도록 개선
- M-P08 AI 답변 감별 결과가 M-P11 1on1 코칭에 연결되도록 개선
- M-P12 실행계획에서 앞선 산출물을 요약 카드로 보여주도록 개선

### 4.2 강사용 화면 보완

- `/instructor-live.html`을 강사용 주 화면으로 사용
- Google Sheets 데이터 기준 참여자별 진행 현황 표시
- 화면별 응답 수 표시
- 안전선 혼동 항목 집계
- AI 위험 문장 집계
- 실행계획 요약 보기
- 우수 사례 후보 표시

### 4.3 저장 구조 보완

현재 Responses 시트에 저장되는 구조는 유지하되, 각 실습 결과에 아래 공통 필드를 강화합니다.

```json
{
  "flowStage": "M-P05",
  "selectedMemberId": "M01",
  "selectedCustomerGroupIds": ["CG-A"],
  "reflectionNote": "...",
  "generatedPrompt": "...",
  "aiAnswer": "...",
  "reviewChecks": ["보안성", "현장성"],
  "finalText": "...",
  "nextAction": "..."
}
```

## 5. v2.1 우선 개발 항목

### 1순위: 실습 간 데이터 연결

- Dashboard에서 선택한 팀원 저장
- 이후 화면에서 같은 팀원을 기본값으로 표시
- 실행계획 화면에서 앞선 산출물 요약 표시

### 2순위: 강사용 Live Dashboard 고도화

- Sheets 조회 기반 참여자별 진행률
- 화면별 완료 현황
- 최근 응답과 위험 문장 확인

### 3순위: 샘플 답변 Bank 강화

- 좋은 답변
- 위로 과잉형
- 압박 과잉형
- CP 위험형
- 현장성 부족형
- 성과책임 약화형

### 4순위: 결과 리포트 구조

- 참여자별 결과 요약
- 팀별 토의용 요약
- 강사용 복사용 결과 텍스트

## 6. 완료 기준

v2.1은 아래 조건을 만족해야 합니다.

- [ ] 참여자 화면 12개가 전체 흐름으로 자연스럽게 이어진다.
- [ ] M-P05에서 선택한 팀원이 M-P06, M-P08, M-P11에 연결된다.
- [ ] M-P12에서 앞선 주요 산출물이 요약된다.
- [ ] 강사용 Live Dashboard에서 Sheets 데이터를 조회할 수 있다.
- [ ] 참여자별 진행 현황과 화면별 응답 현황이 보인다.
- [ ] AI 위험 문장 또는 감별 결과를 강사가 확인할 수 있다.
- [ ] Google Sheets 저장이 유지된다.
- [ ] 기존 `/`, `/?view=check`, `/instructor-live.html` 경로가 모두 정상 작동한다.

- Google Sheets 기반 다중 세션 관리
- 강사용 우수 사례 선택/표시 기능
- 교육 후 사후 실행계획 Follow-up 링크
