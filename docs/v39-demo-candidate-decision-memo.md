## 6. 최종 판단 기준

```text
브라우저 확인에서 큰 문제가 없으면:
  v39를 시연 후보로 동결한다.

문구나 배치의 작은 문제가 보이면:
  v39 preview 안에서만 수정하고 CI를 다시 확인한다.

저장 연결, 화면 이동, 보호 파일, 브라우저 오류 문제가 보이면:
  동결하지 않는다. 수정 후 다시 확인한다.
```
