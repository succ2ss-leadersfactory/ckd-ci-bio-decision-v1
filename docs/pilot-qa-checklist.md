# C1바이오 AI 리더십 Lab 파일럿 전 QA 체크리스트

## 1. 배포·접속 확인

- [ ] Vercel Production 배포가 성공했다.
- [ ] 참여자 앱 `/`이 노트북에서 열린다.
- [ ] 참여자 앱 `/`이 태블릿에서 열린다.
- [ ] 강사용 대시보드 `/?view=instructor`가 열린다.
- [ ] 사전점검 화면 `/?view=check`가 열린다.
- [ ] 화면 새로고침 후에도 앱이 깨지지 않는다.

## 2. Google Sheets + Apps Script 확인

- [ ] Vercel 환경변수 `VITE_GOOGLE_SCRIPT_WEBAPP_URL`이 Production에 등록되어 있다.
- [ ] 재배포 후 `/?view=check`에서 Google Script URL이 “설정됨”으로 표시된다.
- [ ] `ping` 테스트가 성공한다.
- [ ] `setupSheetsC1Bio` 테스트가 성공한다.
- [ ] `saveParticipant` 테스트가 성공한다.
- [ ] `saveResponse` 테스트가 성공한다.
- [ ] `getDashboardData` 테스트가 성공한다.
- [ ] Google Sheets의 `Participants` 시트에 테스트 행이 생성된다.
- [ ] Google Sheets의 `Responses` 시트에 테스트 행이 생성된다.

## 3. 참여자 플로우 확인

- [ ] 세션코드, 이름, 팀명을 입력할 수 있다.
- [ ] `저장하고 다음` 버튼으로 다음 화면으로 이동한다.
- [ ] 12개 화면을 순서대로 이동할 수 있다.
- [ ] AI 안전선 카드 선택 결과가 저장된다.
- [ ] 좋은 질문 만들기 화면에서 프롬프트 복사가 된다.
- [ ] Dashboard Lab에서 데이터 신호와 Gap 가설을 작성할 수 있다.
- [ ] 성과대화 화면에서 AI 답변 붙여넣기와 감별이 가능하다.
- [ ] 1on1 코칭 Lab에서 대화문과 질문을 작성할 수 있다.
- [ ] 실행계획 화면에서 전체 결과 복사가 된다.

## 4. 저장 안정성 확인

- [ ] 화면 이동 시 localStorage에 자동 저장된다.
- [ ] 브라우저 새로고침 후 입력값이 복원된다.
- [ ] Google Sheets 저장 성공 시 상태 문구가 표시된다.
- [ ] Google Sheets 저장 실패 시 pendingSync에 보관된다.
- [ ] 강사용 화면에서 pendingSync 건수를 확인할 수 있다.

## 5. 강사용 대시보드 확인

- [ ] 참여자 응답 JSON을 확인할 수 있다.
- [ ] 응답 화면 수가 표시된다.
- [ ] pendingSync 건수가 표시된다.
- [ ] 교육생 화면에서 입력한 값이 강사용 화면에 반영된다.
- [ ] 점수, 순위, 등급처럼 평가로 보이는 표현이 없다.

## 6. 교육장 운영 확인

- [ ] 교육장 Wi-Fi에서 참여자 앱이 열린다.
- [ ] 교육장 Wi-Fi에서 Google Sheets 저장이 된다.
- [ ] 참여자들이 무료 AI 도구에 접속할 수 있다.
- [ ] AI 접속이 안 되는 경우 사용할 샘플 답변을 준비했다.
- [ ] 강사용 PC에서 대시보드를 띄울 수 있다.
- [ ] 빔프로젝터 또는 대형 모니터에서 화면 글자가 읽힌다.
- [ ] 모바일/태블릿에서 버튼이 충분히 크다.

## 7. 컴플라이언스 확인

- [ ] 주요 화면에 실제 병원명, 의료진명, 제품명, 매출·처방 정보 입력 금지 문구가 보인다.
- [ ] 참여자 입력 예시가 모두 가상 데이터 중심이다.
- [ ] 고객관점 표현이 고객 공략이나 처방 확대 표현으로 흐르지 않는다.
- [ ] AI 답변 감별 기준에 보안성, CP 준수성, 고객가치성, 현장성, 성과책임, 실행가능성, 팀장 역할, 표현 안전성이 포함되어 있다.

## 8. 파일럿 종료 후 확인

- [ ] Responses 시트를 백업했다.
- [ ] Participants 시트를 백업했다.
- [ ] 개인정보 또는 실제 고객정보 입력 여부를 확인했다.
- [ ] 오류 로그와 pendingSync 발생 여부를 기록했다.
- [ ] 교육생 사용성 피드백을 수집했다.
- [ ] 다음 버전 개선 항목을 정리했다.
