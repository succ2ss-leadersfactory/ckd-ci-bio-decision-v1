# v38 기능 클릭 QA 테스트 샘플

## 1. 목적

이 문서는 v38 5단계 `팀원 실행진단`에서 남은 기능 클릭 QA를 빠르게 확인하기 위한 샘플 입력 자료다.

확인 대상:

- AI 추천 지표 자동 분리·채우기
- AI 결과 선택 유형 자동 분리·채우기
- AI 2차 결과를 선택 유형별로 채우기
- 우리 팀 유사 유형 2명 선택 제한
- 선택한 2명만 후속 입력 패널에 반영되는지

---

## 2. QA 전 준비

1. v38 Preview URL에 접속한다.
2. 5단계 `팀원 실행진단`으로 이동한다.
3. 필요하면 `진행 초기화` 후 다시 시작한다.
4. 우리 팀 상황은 1~3개만 선택한다.
5. 아래 샘플을 그대로 붙여넣어 자동분리 버튼을 누른다.

실제 고객명, 병원명, 의료진명, 제품명, 내부 수치, 개인정보는 입력하지 않는다.

---

## 3. 샘플 1: AI 추천 지표 자동 분리·채우기

붙여넣기 위치:

- `AI 추천 지표 붙여넣기`

클릭 버튼:

- `AI 추천 지표 자동 분리·채우기`

예상 결과:

- 핵심 지표 후보 영역에 3개 이상 채워짐
- 보완 지표 후보 영역에 2개 이상 채워짐
- 안전선 지표 후보 영역에 2개 이상 채워짐
- 제외 또는 보류 지표 영역이 있으면 관련 내용이 채워짐

```markdown
# 제약영업 팀장을 위한 실행 관찰 지표 후보

## 1. 핵심 지표 후보

| 지표 | 관찰 포인트 | 왜 필요한가 |
|---|---|---|
| 방문 목적 사전 정의 여부 | 방문 전 이번 방문에서 확인할 내용을 말할 수 있는가 | 활동량은 있지만 고객 반응이 약한 원인 확인 |
| 고객 반응 언어화 수준 | 방문 후 고객 반응을 자기 언어로 설명할 수 있는가 | CRM 기록과 실제 실행 판단의 연결 확인 |
| 후속조치 실행 시점 | 방문 후 연락이나 자료 전달이 며칠 이내 이루어지는가 | 방문 후 실행 단절 문제 확인 |
| 다음 방문 준비 내용 | 이전 방문의 확인 내용이 다음 방문 준비에 반영되는가 | 방문을 독립 이벤트가 아니라 연속 실행으로 보는지 확인 |

## 2. 보완 지표 후보

| 지표 | 관찰 포인트 |
|---|---|
| 고객 단계 구분 기준 보유 여부 | 고객별 접근 빈도와 대화 방식을 다르게 가져가는 기준이 있는가 |
| 정보 활용 행동 | 학술자료나 내부 자료를 방문 준비에 연결하는가 |
| CRM 기록 실용성 | 기록을 다시 꺼내 다음 행동에 활용하는가 |

## 3. 안전선 지표 후보

| 지표 | 확인 포인트 | 팀장 활용 방법 |
|---|---|---|
| 허용 범위 내 자료 활용 기준 인지 | 사용 가능한 자료와 그렇지 않은 자료를 구분할 수 있는가 | 교육 확인이 아니라 실제 판단 기준 확인 |
| 경계 상황 대응 경험 | 모호한 요청을 받았을 때 어떻게 대응했는가 | 사례 기반 1:1 대화로 진입 |
| 불확실 상황 보고 행동 | 애매한 상황에서 혼자 처리하지 않고 먼저 묻는가 | 보고 문화와 심리적 안전감 확인 |

## 4. 채택 전 보류할 지표

| 지표 후보 | 보류 이유 |
|---|---|
| 방문 건수 목표 달성률 | 이미 활동량은 충분해 질적 개선 동기를 약화시킬 수 있음 |
| 고객 반응 점수화 | 숫자 관리로 행동이 왜곡될 수 있음 |
| CRM 기록 건수 | 기록의 양만 늘리고 실행 판단에는 연결되지 않을 수 있음 |
```

## 4. 샘플 2: AI 결과 선택 유형 자동 분리·채우기

사전 선택:

- 7명 유형 카드에서 `박재욱 사원`, `문교원 사원` 2명을 선택한다.
- 3번째 유형 선택이 제한되는지 확인한다.

붙여넣기 위치:

- `AI 결과 붙여넣기`

클릭 버튼:

- `AI 결과 선택 유형 자동 분리·채우기`

예상 결과:

- 박재욱 사원, 문교원 사원만 신호 분리 정리 영역에 표시됨
- 각 유형의 관찰 신호, 강점 신호, 우려 신호, 확인 질문, 단정 금지 내용이 채워짐

```markdown
# 선택한 유형별 분리 정리

## 박재욱 사원

### 팀원별 관찰 신호
- CRM 기록은 꼼꼼하지만 고객 앞에서 질문이 짧게 끝나는 경향이 있다.
- 방문 준비 자료는 확인하지만, 고객 반응에 따라 대화를 전환하는 장면은 적다.
- 본인은 성실하게 준비한다고 느끼지만 실제 고객 대화에서는 조심스러운 태도가 강하다.

### 강점으로 볼 수 있는 신호
- 기록 습관이 안정적이어서 코칭 후 실행 추적이 가능하다.
- 기본 자료 확인과 준비 태도는 갖춰져 있다.
- 무리하게 약속하거나 과장해서 말하지 않는 점은 안전선 측면에서 강점이다.

### 우려 또는 확인이 필요한 신호
- 준비가 실제 대화 전환으로 이어지지 않을 수 있다.
- 고객 질문에 즉시 반응하기보다 안전한 답변만 반복할 가능성이 있다.
- 방문 후 스스로 무엇이 막혔는지 설명하기 어려울 수 있다.

### 추가로 확인해야 할 질문
- 최근 방문 중 고객이 관심을 보인 지점은 무엇이었나요?
- 그 반응을 보고 다음 방문에서는 무엇을 다르게 준비할 수 있을까요?
- 질문을 꺼내기 어려웠던 순간이 있었다면 어떤 상황이었나요?

### 성급하게 단정하면 안 되는 점
- 소극적이라고 단정하지 않는다.
- 실행 의지가 부족하다고 보기 전에 대화 구조와 질문 준비 방식부터 확인한다.

## 문교원 사원

### 팀원별 관찰 신호
- 입사 초기에는 질문이 많았지만 최근에는 질문 빈도가 줄었다.
- 지시는 이해했다고 말하지만 실행물에서는 해석 차이가 나타난다.
- 피드백 이후 대화가 짧아지고 표정이나 반응이 조심스러워졌다.

### 강점으로 볼 수 있는 신호
- 초반 질문이 많았다는 것은 학습 의지가 있었다는 신호일 수 있다.
- 지시를 따르려는 태도는 있으나 표현 방식이 조심스러울 수 있다.
- 고객 방문 시간 관리 등 기본 실행 습관을 만들 여지가 있다.

### 우려 또는 확인이 필요한 신호
- 이해하지 못한 것을 숨기고 혼자 해결하려 할 수 있다.
- 상명하복식 피드백을 개인적 부정으로 받아들일 수 있다.
- 일의 의미와 기대 수준을 충분히 이해하지 못하면 이탈 위험이 커질 수 있다.

### 추가로 확인해야 할 질문
- 최근 업무 중 가장 헷갈렸던 지시는 무엇이었나요?
- 피드백을 받은 뒤 다음 행동으로 무엇을 바꿔야 한다고 이해했나요?
- 지금 역할에서 가장 막막하게 느껴지는 부분은 무엇인가요?

### 성급하게 단정하면 안 되는 점
- MZ세대라서 참을성이 부족하다고 단정하지 않는다.
- 질문이 줄었다는 이유만으로 관심이 없다고 해석하지 않는다.
```

## 5. 샘플 3: AI 2차 결과를 선택 유형별로 채우기

사전 조건:

- `박재욱 사원`, `문교원 사원` 2명이 선택된 상태
- 각 유형별로 추천 준비물 선택 버튼을 한 번 누르거나 준비물 체크박스를 직접 선택한다.

붙여넣기 위치:

- `AI 2차 결과 붙여넣기`

클릭 버튼:

- `AI 2차 결과를 선택 유형별로 채우기`

예상 결과:

- 박재욱 사원, 문교원 사원의 `AI가 제안한 준비물 초안` 영역에 내용이 채워짐
- 최종 준비물 입력칸은 별도로 수정 가능해야 함

```markdown
# 선택 유형별 다음 행동 준비물 초안

## 박재욱 사원

### 1on1 대화 시작 문장
박재욱 사원, 최근 기록과 준비는 꾸준히 하고 있는 것으로 보입니다. 오늘은 잘하고 있는 부분을 먼저 확인하고, 그 준비가 고객 대화에서 더 잘 살아나려면 무엇을 바꾸면 좋을지 같이 보려고 합니다.

### 확인 질문
- 최근 방문 중 고객 반응이 예상과 달랐던 순간은 언제였나요?
- 그때 어떤 질문을 더 해볼 수 있었을까요?
- 다음 방문 전에 한 가지 질문만 준비한다면 무엇을 준비하겠어요?

### 다음 행동 약속
다음 주 방문 2건에 대해 방문 전 질문 1개와 방문 후 고객 반응 요약 2줄을 남긴다.

### 팀장 관찰 포인트
기록의 양보다 기록이 다음 대화 준비로 연결되는지 확인한다.

## 문교원 사원

### 1on1 대화 시작 문장
문교원 사원, 요즘 일을 익히는 과정에서 헷갈리는 부분이 있을 수 있다고 봅니다. 오늘은 잘잘못을 따지기보다 지시를 어떻게 이해했고 어디에서 막혔는지 함께 정리해보려고 합니다.

### 확인 질문
- 최근에 지시를 받고도 다시 묻기 어려웠던 상황이 있었나요?
- 피드백을 받은 뒤 무엇을 바꾸면 된다고 이해했나요?
- 지금 업무에서 가장 먼저 명확해졌으면 하는 기준은 무엇인가요?

### 다음 행동 약속
다음 1주일 동안 업무 지시를 받은 뒤 본인이 이해한 내용을 한 문장으로 다시 확인한다.

### 팀장 관찰 포인트
질문 빈도보다 질문할 수 있는 안전감이 회복되는지 확인한다.
```

## 6. 빠른 판정 기준

| 기능 | 통과 기준 |
|---|---|
| 유형 2명 선택 제한 | 2명 선택 후 3번째 선택이 제한됨 |
| AI 추천 지표 자동분리 | 핵심/보완/안전선 영역에 내용이 분리되어 들어감 |
| AI 신호 정리 자동분리 | 선택한 2명만 분리 패널에 표시되고 내용이 채워짐 |
| AI 2차 준비물 자동 채우기 | 선택한 2명의 준비물 초안 영역에 내용이 채워짐 |
| 최종 입력칸 | AI 초안과 별도로 팀장이 수정 가능함 |
