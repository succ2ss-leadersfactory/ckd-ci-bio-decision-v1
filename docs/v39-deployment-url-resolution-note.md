## 3. Why this note is needed

The repository does not currently contain a fixed Vercel deployment URL string for v39.

Repository search for Vercel URL markers did not return a stable URL entry.

Therefore, the actual browser QA URL should be copied from Vercel's deployment page or GitHub deployment/check output, then combined with:

```text
/journey-v39-preview.html
```

## 4. URL format to use

Use the actual Vercel deployment host, then append the v39 route path:

```text
https://<actual-vercel-deployment-host>/journey-v39-preview.html
```

Examples of acceptable host sources:

```text
Vercel preview deployment URL for the latest commit
Vercel branch deployment URL for feature/v37-preview-shell
GitHub check/deployment details URL if Vercel posts one
```

## 5. Important DNS caution

Do not rely on a guessed long branch-based hostname if the first DNS label becomes too long.

For example, a hostname generated by directly combining project name + branch name + team name can exceed valid DNS label length.

If a guessed URL fails before loading the page, use the deployment URL directly provided by Vercel instead of manually constructing the host.

The route path should remain:

```text
/journey-v39-preview.html
```

Only the host should change.

## 7. Browser QA first checks

After opening the URL, verify:

```text
Page loads without 404
No 502 Bad Gateway
No blank white screen
Header says C1바이오 영업팀장 AI 리더십 Lab Journey
Route path is /journey-v39-preview.html
Console has no uncaught error
```

## 8. If the URL fails

Record:

```text
URL attempted
Browser/device
HTTP or browser error
Console/network error if available
Whether the host was copied from Vercel or guessed manually
Latest tested commit SHA
```

Then use the Vercel dashboard or GitHub deployment details to copy the exact generated preview URL.

## 9. Do not modify protected files for URL issues

A deployment URL problem should not require modifying protected app files.

Protected files remain off-limits:

```text
journey.html
src/full-flow-journey-v34.tsx
src/journey-active.tsx
src/full-flow-journey-v35.tsx
src/journey-v38-app-preview.tsx
```

Fix only v39 preview files if the deployed page loads but the v39 journey has a confirmed UI/runtime issue.
