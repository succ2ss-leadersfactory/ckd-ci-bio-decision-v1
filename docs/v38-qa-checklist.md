# v38 QA Checklist

## 1. 목적

v38은 v37의 DOM 후처리 방식 문제를 반복하지 않기 위해, 정식 React 컴포넌트 방식으로 복구·확장한 Preview Journey다.

본 체크리스트의 목적은 다음과 같다.

- v34 운영 화면 보호 확인
- v36 고객사 시연 확인용 Preview 보호 확인
- v38 12단계 전체 흐름 확인
- 모바일/태블릿 사용성 확인
- 제약영업 AI 안전선과 컴플라이언스 표현 점검
- 고객사 시연 전 수정 우선순위 도출

- [x] 고객군 후보 1~6이 개별 고객 6명이 아니라 가상 고객군 후보임을 안내한다.
- [x] 고객군 후보 1~6을 접기/펼치기 카드 구조로 제공한다.
- [x] 첫 번째 고객군 후보만 기본 펼침으로 제공한다.
- [x] `6개 고객군, 먼저 이렇게 읽어보세요` 섹션을 접기/펼치기 구조로 제공한다.

- [x] 고객군 후보별 특징 요약은 분류명을 정답처럼 단정하지 않고 첫 인상 도움말로 제공한다.
- [x] 각 고객군 후보에서 기회성, 반응성, 실행 가능성, 리스크가 한 카드 안에 보인다.

- [x] 13개 Data가 `기회성 Data`, `반응성 Data`, `실행 가능성 Data`, `리스크 Data`로 묶여 표시된다.
- [x] 각 Data 항목에 `긍정 신호`, `판단 유보`, `주의 신호`, `보완 필요` 평가 라벨이 표시된다.

- [x] `컴플라이언스 중간`은 `주의 신호`로 표시된다.
- [x] 분류 도우미가 `가장 강한 신호`, `2주 행동 방향`, `가장 큰 주의점`으로 판단을 돕는다.
- [x] 최종 고객군 분류 선택이 가능하다.
- [x] 분류 이유를 직접 작성할 수 있다.
- [x] 분류 완료 수가 정상 반영된다.
- [x] 7단계 집중/후순위 고객군 선택과 개념적으로 연결된다.

### 6-2. 고객사 확인 전 필수 QA

- [ ] 고객군 후보 1~6을 모두 열어도 화면이 깨지지 않는다.
- [ ] `6개 고객군, 먼저 이렇게 읽어보세요` 섹션이 `전체 고객군 한눈에 보기` 아래에 표시된다.
- [ ] 고객군 후보별 특징 요약이 접기/펼치기 구조로 제공되어 화면 부담이 크지 않다.
- [ ] 고객군 후보별 특징 요약에 `핵심 특징`, `강한 신호`, `주의 신호`, `판단 질문`이 보인다.
- [ ] 고객군 후보별 특징 요약이 분류 정답표처럼 보이지 않고 첫 인상 도움말로 이해된다.

- [ ] 참여자가 고객군 후보별로 최종 분류를 선택할 수 있다.

- [ ] 8단계 팀원별 역할 방향으로 자연스럽게 넘어갈 수 있다.

---

## 8. 팀원별 역할 방향 QA

- [ ] 팀원 4명의 프로필이 보인다.
- [ ] 팀원별 담당 고객군을 선택할 수 있다.
- [ ] 팀원별 실행 역할을 선택할 수 있다.
- [ ] 팀장 코칭 포인트를 선택할 수 있다.
- [ ] 컴플라이언스 주의 안내를 작성할 수 있다.
- [ ] 팀원별 역할 배분 요약이 표시된다.

---

## 9. AI 콜플랜 요청 QA

- [ ] 입력 금지 기준이 명확하게 보인다.
- [ ] AI에 요청할 결과물을 여러 개 선택할 수 있다.
- [ ] 선택한 결과물만 프롬프트에 반영된다.
- [ ] 판단 맥락을 체크박스로 선택할 수 있다.
- [ ] 추가 요청을 입력할 수 있다.
- [ ] 복사용 AI 프롬프트가 생성된다.
- [ ] 프롬프트 복사 버튼이 작동한다.
- [ ] 프롬프트에 실제 고객명, 병원명, 의료진명, 제품명 입력 유도 문구가 없다.

---

## 10. 컴플라이언스 위험 표현 제거 QA

- [ ] 위험 표현 유형이 명확하게 제시된다.
- [ ] AI 초안 표현을 보고 위험 유형을 선택할 수 있다.
- [ ] 안전한 대체 문장을 직접 작성할 수 있다.
- [ ] 안전 표현 예시 사용 버튼이 작동한다.
- [ ] 내 콜플랜 문장을 직접 점검할 수 있다.
- [ ] 처방 유도, 비교 우위 단정, 허가 외 표현, 민감정보 포함, 과도한 약속 표현이 구분된다.

## 11. 최종 2주 콜플랜 카드 QA

- [ ] 집중 고객군을 작성할 수 있다.
- [ ] 후순위 고객군을 작성할 수 있다.
- [ ] 관찰/유지 고객군을 작성할 수 있다.
- [ ] 팀원별 역할을 작성할 수 있다.
- [ ] 2주 실행 우선순위를 작성할 수 있다.
- [ ] 컴플라이언스 주의점을 작성할 수 있다.
- [ ] 팀원에게 말할 첫 실행 문장을 작성할 수 있다.
- [ ] 예시 템플릿 채우기 버튼이 작동한다.
- [ ] 카드 내용 복사 버튼이 작동한다.
- [ ] 카드가 프롬프트처럼 보이지 않고 현업 실행카드처럼 보인다.

- [ ] 팀원별 역할 방향 토의 질문이 있다.
- [ ] AI 활용 디브리핑 질문이 있다.
- [ ] 컴플라이언스와 최종 실행카드 토의 질문이 있다.
- [ ] 강사용 질문이 교육생 화면을 과도하게 방해하지 않는다.
