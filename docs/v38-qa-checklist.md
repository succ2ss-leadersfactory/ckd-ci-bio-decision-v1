# v38 QA Checklist

## 1. 목적

v38은 v37의 DOM 후처리 방식 문제를 반복하지 않기 위해, 정식 React 컴포넌트 방식으로 복구·확장한 Preview Journey다.

본 체크리스트의 목적은 다음과 같다.

- v34 운영 화면 보호 확인
- v36 고객사 시연 확인용 Preview 보호 확인
- v38 12단계 전체 흐름 확인
- 5단계 팀원 실행진단의 최신 구조 확인
- 모바일/태블릿 사용성 확인
- 제약영업 AI 안전선과 컴플라이언스 표현 점검
- 고객사 시연 전 수정 우선순위 도출
