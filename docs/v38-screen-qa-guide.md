# v38 화면 QA 가이드

## 1. 목적

이 문서는 고객사 시연 또는 교육장 파일럿 전에 강사/운영자가 v38 화면을 직접 눌러보며 빠르게 확인하기 위한 실행형 점검 가이드다.

개발자용 세부 체크리스트는 `docs/v38-qa-checklist.md`를 기준으로 하고, 이 문서는 실제 화면 확인 순서에 집중한다.

---

## 2. 접속 기준

최신 Vercel 배포 URL 뒤에 다음 경로를 붙여 접속한다.

```text
/journey-v38-preview.html
```

확인 전 브라우저에서 이전 입력값이 남아 있다면 다음 중 하나를 수행한다.

- `v38 진행 초기화` 버튼 사용
- 브라우저 사이트 데이터 삭제
- 시크릿 모드에서 접속

---

## 3. 5분 빠른 정상성 확인

아래 항목이 모두 정상이면 화면 전체가 크게 깨진 상태는 아니다.

- [ ] 1단계 입장 화면이 열린다.
- [ ] 상단에 12개 단계가 보인다.
- [ ] `다음 단계` 버튼으로 단계 이동이 된다.
- [ ] 5단계 `팀원 실행진단`으로 이동된다.
- [ ] 5단계에서 `우리 팀 지표로 다음 행동 준비하기` 제목이 보인다.
- [ ] 7명 유형 카드가 보인다.
- [ ] `문교원 사원` 카드가 보인다.
- [ ] 12단계까지 이동된다.
- [ ] 고객사 시연 화면에 `QA`, `smoke`, `preview shell`, `검증용` 같은 내부 문구가 노출되지 않는다.

---

## 4. 5단계 핵심 흐름 QA

5단계는 v38의 핵심 실습 화면이다. 다음 순서대로 확인한다.

### 4.1 우리 팀 상황 선택

- [ ] 처음 진입 시 상황 선택값이 없다.
- [ ] 상황은 최대 3개까지만 선택된다.
- [ ] 4번째 선택은 제한된다.
- [ ] 선택을 해제하면 다른 항목을 다시 선택할 수 있다.

### 4.2 AI 추천 지표 자동분리

1. `AI 지표 추천 프롬프트 복사` 버튼을 누른다.
2. 외부 AI에 붙여넣어 결과를 생성한다.
3. 생성 결과를 `AI 추천 지표 붙여넣기`에 붙여넣는다.
4. `AI 추천 지표 자동 분리·채우기` 버튼을 누른다.

확인 항목:

- [ ] 핵심 지표 후보가 채워진다.
- [ ] 보완 지표 후보가 채워진다.
- [ ] 안전선 지표 후보가 채워진다.
- [ ] 제외할 지표 또는 추가 지표 영역이 채워지거나 비어 있어도 안내가 자연스럽다.
- [ ] 자동분리 결과가 정답처럼 보이지 않고 수정 가능한 초안으로 보인다.

### 4.3 우리 팀 핵심 실행지표 최종 선택

- [ ] 처음 진입 시 선택된 지표가 없다.
- [ ] 핵심 지표는 최대 3개까지 선택된다.
- [ ] 보완 지표는 최대 2개까지 선택된다.
- [ ] 안전선 지표는 최대 1개까지 선택된다.
- [ ] 선택 이유를 입력할 수 있다.

### 4.4 7명 유형 카드와 2명 선택

7명 유형 카드 순서는 다음과 같아야 한다.

1. 김재호 차장
2. 김문호 차장
3. 유희관 과장
4. 이대은 대리
5. 신재영 대리
6. 박재욱 사원
7. 문교원 사원

확인 항목:

- [ ] 위 순서대로 표시된다.
- [ ] `문교원 사원`은 신입·저연차, MZ세대 소통, 이탈 위험 점검 맥락으로 보인다.
- [ ] 유형은 최대 2명까지만 선택된다.
- [ ] 3번째 유형 선택은 제한된다.
- [ ] 선택 해제 후 다른 유형을 선택할 수 있다.
- [ ] 나머지 5명은 참고 자료로만 사용한다는 안내가 보인다.

### 4.5 AI 신호 정리 자동분리

1. 유형 2명을 선택한다.
2. `AI 신호 정리 프롬프트 복사` 버튼을 누른다.
3. 외부 AI에 붙여넣어 결과를 생성한다.
4. 생성 결과를 `AI 결과 붙여넣기`에 붙여넣는다.
5. `AI 결과 선택 유형 자동 분리·채우기` 버튼을 누른다.

확인 항목:

- [ ] 선택한 2명만 입력 패널에 표시된다.
- [ ] `팀원별 관찰 신호`가 채워진다.
- [ ] `강점으로 볼 수 있는 신호`가 채워진다.
- [ ] `우려 또는 확인이 필요한 신호`가 채워진다.
- [ ] `추가로 확인해야 할 질문`이 채워진다.
- [ ] `성급하게 단정하면 안 되는 점`이 채워진다.
- [ ] 자동분리가 실패한 유형이 있으면 안내 문구가 보인다.

### 4.6 팀장 행동 선택

- [ ] 선택한 2명에 대해서만 팀장 행동 선택 카드가 표시된다.
- [ ] `추천 준비물 선택` 버튼을 누르면 추천 준비물이 선택된다.
- [ ] 준비물 체크박스를 직접 선택하거나 해제할 수 있다.
- [ ] 선택 상태가 시각적으로 구분된다.

### 4.7 AI 2차 준비물 자동 채우기

1. `AI 준비물 생성 프롬프트 복사` 버튼을 누른다.
2. 외부 AI에 붙여넣어 결과를 생성한다.
3. 생성 결과를 `AI 2차 결과 붙여넣기`에 붙여넣는다.
4. `AI 2차 결과를 선택 유형별로 채우기` 버튼을 누른다.

확인 항목:

- [ ] 선택한 2명의 `AI가 제안한 준비물 초안`에 결과가 채워진다.
- [ ] `최종 유형별 다음 행동 준비물`은 별도로 수정할 수 있다.
- [ ] AI 초안과 팀장 최종 판단 입력칸이 구분되어 보인다.
- [ ] 실제 팀원에게 사용할 문장과 행동은 팀장이 수정해야 한다는 안내가 보인다.

## 5. 6~8단계 연결 QA

### 5.1 6단계 고객 Data 분석

- [ ] 고객 유형 A~F가 보인다.
- [ ] 고객 Data 분석 흐름이 정답표처럼 보이지 않는다.
- [ ] 참여자가 자신의 판단을 입력할 수 있다.

### 5.2 7단계 고객 유형별 대응 전략

- [ ] 고객 유형별 대응 전략을 선택할 수 있다.
- [ ] `AI 전략 점검 프롬프트 복사` 버튼이 보인다.
- [ ] 6단계의 고객 판단과 자연스럽게 연결된다.

### 5.3 8단계 팀원별 역할 방향

- [ ] 현재 8단계는 기존 6명 역할 방향 구조다.
- [ ] `문교원 사원`이 8단계에 아직 반영되지 않은 것이 교육 흐름상 어색하지 않은지 확인한다.
- [ ] `김민재 프로`, `이서연 프로`, `정하늘 프로`, `최도윤 프로`가 표시되지 않는다.
- [ ] 9단계 AI 콜플랜 요청으로 자연스럽게 넘어간다.

## 6. 모바일/태블릿 QA

가능하면 Galaxy Z Fold, Galaxy Tab, iPad 중 하나 이상에서 확인한다.

- [ ] 단계 칩이 좌우 스크롤된다.
- [ ] 카드가 한 줄로 찌그러지지 않는다.
- [ ] 5단계 7명 유형 카드가 너무 답답하게 보이지 않는다.
- [ ] textarea 입력 시 화면이 심하게 밀리지 않는다.
- [ ] 하단 이전/다음 버튼이 키보드에 가려져도 다시 접근 가능하다.
- [ ] 5단계에서 선택한 2명 입력 패널을 실제 교육생이 따라갈 수 있는 길이로 느낀다.

## 7. 컴플라이언스 QA

- [ ] 실제 고객명, 병원명, 의료진명 입력 금지 안내가 보인다.
- [ ] 제품명, 미승인 제품 표현, 내부 전략 수치, 개인정보 입력 금지 안내가 보인다.
- [ ] AI 프롬프트에 민감정보를 넣지 말라는 안내가 포함되어 있다.
- [ ] 10단계에서 위험 표현을 안전한 표현으로 수정할 수 있다.

## 8. 최종 판정

### 통과

아래 조건을 만족하면 고객사 시연 또는 파일럿용으로 사용 가능하다.

- [ ] v38 12단계가 모두 열린다.
- [ ] 5단계 핵심 흐름이 끊기지 않는다.
- [ ] 유형 2명 선택 제한이 작동한다.
- [ ] AI 자동분리 3종이 모두 작동한다.
- [ ] 모바일/태블릿에서 진행 가능하다.
- [ ] 컴플라이언스 안내가 충분히 보인다.
- [ ] GitHub Actions `v38 Smoke`가 success다.

### 보류

아래 항목 중 하나라도 있으면 고객사 시연 전 수정한다.

- [ ] 5단계가 렌더링되지 않는다.
- [ ] 유형 2명 제한이 작동하지 않는다.
- [ ] 자동분리 버튼이 동작하지 않는다.
- [ ] 문교원 사원 카드가 표시되지 않는다.
- [ ] 고객사 화면에 내부 개발 문구가 노출된다.
- [ ] 모바일에서 입력 자체가 어렵다.

## 9. 권장 QA 기록 방식

QA 중 발견 사항은 다음 형식으로 기록한다.

```text
[단계]
예: 5단계 팀원 실행진단

[문제]
예: 문교원 사원 카드 설명이 너무 길어 모바일에서 한 화면을 많이 차지함

[심각도]
P0 / P1 / P2 / P3

[수정 제안]
예: 문교원 사원 카드 설명을 2줄로 줄이고, 세부 설명은 신호 태그로 분리
```

심각도 기준:

- P0: 시연 불가, 기능 중단, 화면 깨짐
- P1: 고객사 시연 전 반드시 수정해야 하는 흐름 문제
- P2: 시연 가능하지만 교육 몰입을 낮추는 사용성 문제
- P3: 문구, 여백, 표현 방식 미세수정
