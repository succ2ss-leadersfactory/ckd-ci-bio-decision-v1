# v39 Field Language Residual Audit

이 문서는 v39 5~13단계 화면의 현장언어화 작업 후 남아 있을 수 있는 기계어·전문어 표현을 관리하기 위한 감사표다.

## 1. 감사 목적

v39는 기능적으로는 5~13단계 연결 흐름이 안정화되었다. 이후 화면 문구를 실제 교육생이 이해하기 쉬운 현장언어로 바꾸는 작업을 진행했다.

이 문서의 목적은 아래 세 가지다.

1. 실제 참여자 화면에 보이는 딱딱한 표현을 줄인다.
2. smoke marker, QA 문서, 개발 문서에 남겨야 하는 표현은 무리하게 지우지 않는다.
3. 브라우저 QA 때 남은 표현을 빠르게 확인한다.

## 2. 현장언어화 기준

| 기존 느낌 | 현장언어 기준 |
|---|---|
| 고객 Data | 고객 활동 기록, 방문·면담 기록, 고객 반응 기록 |
| 컴플라이언스 | 말해도 되는 선, 회사 기준에 맞는 표현, 조심할 표현 |

| 산출물 | 남길 것, 메모, 가져갈 것 |
| 프롬프트 | AI에게 붙여넣을 질문, AI에게 부탁할 질문 |

## 4. 보존해야 하는 표현

아래 표현은 실제 참여자 화면에 보이면 어색할 수 있지만, smoke marker나 QA 문서에서는 보존될 수 있다.

| 표현 | 보존 이유 | 조치 |
|---|---|---|
| 고객 Data | 기존 v39 smoke marker, 과거 QA 기준과 호환 | 실제 화면 노출 여부만 확인 |
| 컴플라이언스 | smoke marker, 문서/검증 용어 | 화면에서는 말해도 되는 선으로 대체 |
| Map | 기존 파일명/marker/검증 문구 | 화면에서는 역할 정리, 실행 메모로 대체 |
| 프롬프트 | AI 기능 설명 및 smoke marker | 화면에서는 AI에게 붙여넣을 질문으로 대체 |
| 강사용 | 문서명, QA 설명, 내부 운영 용어 | 화면에서는 함께 이야기할 질문으로 대체 |
| 판단 근거·보완 지점·토의거리 | 13단계 기존 marker | 화면에서는 왜 그렇게 봤는지, 어디가 막힐 수 있는지, 함께 물어볼 질문으로 대체 |

## 5. 브라우저 QA에서 추가 확인할 표현

아래 표현은 실제 화면에 보이면 맥락에 따라 수정 대상이다.

| 확인 표현 | 화면에 보여도 되는 경우 | 수정 권장 표현 |
|---|---|---|
| 고객 Data | 내부 QA 문구, 숨겨진 smoke marker | 고객 활동 기록, 방문·면담 기록 |
| 컴플라이언스 | 법규·회사 기준을 직접 설명하는 강사용 맥락 | 말해도 되는 선, 조심할 표현 |
| Map | 화면 제목이나 버튼에 단독 사용될 때는 부적절 | 역할 정리, 2주 행동 메모 |
| 산출물 | 교육 설계 문서에서는 가능 | 남길 것, 메모 |
| 프롬프트 | AI 실습의 기술적 설명이 꼭 필요할 때만 가능 | AI에게 붙여넣을 질문 |
| AI 실행계획 | 내부 단계명으로는 가능 | AI가 정리한 2주 실행 초안 |
| 강사용 토의 | 내부 운영 문서에서는 가능 | 교육장에서 함께 이야기할 질문 |
| 판단 근거 | 카드 제목으로는 다소 딱딱함 | 왜 그렇게 봤는지 |
| 보완 지점 | 카드 제목으로는 다소 딱딱함 | 어디가 막힐 수 있는지 |
| 토의거리 | 내부 문서에서는 가능 | 함께 물어볼 질문 |
