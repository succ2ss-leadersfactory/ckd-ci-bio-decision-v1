# v39 Field-Language Copy Revision Guide

## 1. Revision principle

The current v39 Phase 1 screens are functionally stable, but some copy still reads like system-generated UI text. The next copy pass should make the language feel closer to Korean company meetings, leadership workshops, internal reports, business columns, and workplace narratives.

The goal is not to make the text literary. The goal is to make the wording sound like something a Korean team leader would actually read, say, and use in a workshop room.

## 2. Copy direction

### Avoid

```text
진행 가이드
저장 상태
최소 결과물
이 단계에서 하는 일
이전 단계에서 가져온 것
다음 단계로 넘길 것
선택 고객 유형
고객 Data 판단 상태
AI 실행계획 프롬프트
컴플라이언스 위험 표현 제거
```

### Prefer

```text
이번 화면에서 볼 것
지금까지 남긴 메모
오늘 정리할 것
앞에서 확인한 내용
다음 화면에서 이어 쓸 내용
먼저 볼 고객군
고객 반응에서 읽어야 할 것
AI에 물어볼 실행 질문
현장에서 쓰기 전에 표현 다듬기
```

## 3. Tone standard

Use a tone that is:

```text
clear but not stiff
practical but not dry
workplace-realistic but not slangy
warm but not sentimental
leader-facing rather than developer-facing
```

## 4. Screen-level copy replacements

### Step 5: Team execution diagnosis

Current feeling:

```text
팀원 실행 Data를 역할 판단의 근거로 정리합니다
```

Recommended field-language copy:

```text
숫자만 보지 말고, 팀원별 움직임이 어디서 갈리는지 먼저 짚어봅니다.
```

Recommended card labels:

```text
팀에서 잡힌 신호
눈여겨볼 팀원
현재 메모
```

Recommended explanatory copy:

```text
누가 열심히 했는지보다, 어디에서 실행이 끊기고 어디에서 기준이 흔들렸는지를 봅니다.
```

### Step 6: Customer Data analysis

Current feeling:

```text
고객 Data에서 기회와 착시를 분리합니다
```

Recommended field-language copy:

```text
고객 반응을 바로 기회로 단정하지 말고, 확인해야 할 신호와 놓치기 쉬운 위험을 나눠봅니다.
```

Recommended card labels:

```text
고객 반응 메모
먼저 볼 고객군
현재 판단 메모
```

Recommended explanatory copy:

```text
반응이 좋다는 말만으로 우선순위를 정하지 않습니다. 기회 신호, 조심해야 할 해석, 더 물어봐야 할 질문을 분리합니다.
```

### Step 7: Customer-type response strategy

Current feeling:

```text
고객 판단을 2주 대응 전략으로 바꿉니다
```

Recommended field-language copy:

```text
고객별 판단을 이번 2주 안에 움직일 수 있는 대응안으로 좁힙니다.
```

Recommended card labels:

```text
먼저 볼 고객군
앞 단계 판단 메모
이번 단계 전략 메모
```

Recommended explanatory copy:

```text
고객을 등급으로 나누는 시간이 아닙니다. 팀이 이번 2주 동안 어디에 힘을 실을지 정하는 시간입니다.
```

### Step 8: Member role direction

Current feeling:

```text
고객 전략을 팀원 역할과 코칭 포인트로 바꿉니다
```

Recommended field-language copy:

```text
고객 전략을 팀원별 역할, 준비할 질문, 팀장이 도와야 할 지점으로 풀어냅니다.
```

Recommended card labels:

```text
팀에서 보인 신호
고객 대응안
역할 메모
```

Recommended explanatory copy:

```text
자동 배정이 아닙니다. 팀장이 사람과 상황을 함께 보고 역할 초안을 잡는 과정입니다.
```

### Step 9: Member execution dialogue

Current feeling:

```text
대화 상황을 고르고, 첫마디를 실행 대화로 바꿉니다
```

Recommended field-language copy:

```text
팀원이 방어적으로 듣지 않도록, 첫마디부터 다시 잡아봅니다.
```

Recommended card labels:

```text
앞에서 잡은 역할
대화 메모
```

Recommended explanatory copy:

```text
평소처럼 꺼내는 말이 팀원에게는 압박이나 비교로 들릴 수 있습니다. 이번에는 목적에 맞는 첫 문장부터 다시 씁니다.
```

### Step 10: AI execution plan prompt

Current feeling:

```text
팀원 역할과 실행 대화를 AI 실행계획 프롬프트로 연결합니다
```

Recommended field-language copy:

```text
팀장이 정리한 맥락을 바탕으로, AI에 물어볼 실행 질문을 만듭니다.
```

Recommended card labels:

```text
역할 메모
대화 메모
AI 질문 메모
```

Recommended explanatory copy:

```text
AI에게 결정을 맡기는 단계가 아닙니다. 팀장이 이미 본 맥락을 더 정돈하고 빠진 부분을 점검하는 단계입니다.
```

### Step 11: Compliance cleanup

Current feeling:

```text
AI 실행계획 초안을 안전한 실행 문장으로 정리합니다
```

Recommended field-language copy:

```text
현장에서 그대로 말하기 전에, 오해될 표현과 위험한 문장을 걷어냅니다.
```

Recommended card labels:

```text
AI 초안
손볼 문장
안전 문장 메모
```

Recommended explanatory copy:

```text
좋은 실행안도 표현이 거칠면 현장에서 문제가 됩니다. 단정, 비교, 압박, 민감한 표현을 걷어내고 팀장이 책임질 수 있는 문장으로 다듬습니다.
```

### Step 12: Final two-week execution card

Current feeling:

```text
고객 실행·팀원 역할·안전 문장을 2주 실행 카드로 통합합니다
```

Recommended field-language copy:

```text
이번 2주 동안 실제로 움직일 계획을 한 장으로 정리합니다.
```

Recommended card labels:

```text
역할 반영
대화·표현 반영
최종 카드 메모
```

Recommended explanatory copy:

```text
고객 대응만 적는 카드가 아닙니다. 팀원이 어떻게 움직일지, 팀장이 어떤 말로 시작할지, 어떤 표현은 피할지까지 한 장에 담습니다.
```

### Step 13: Instructor discussion questions

Current feeling:

```text
최종 실행 카드를 강사용 토의 질문으로 전환합니다
```

Recommended field-language copy:

```text
마지막으로, 팀장의 판단을 함께 뜯어볼 질문으로 바꿉니다.
```

Recommended card labels:

```text
최종 카드
토의 거리
운영 준비
```

Recommended explanatory copy:

```text
이 화면은 평가표가 아닙니다. 왜 그렇게 판단했는지, 현장에 가져가면 어디서 막힐지, 더 안전하게 바꾸려면 무엇을 손봐야 할지를 이야기하기 위한 자료입니다.
```

## 5. Recommended implementation method

Because static smoke checks currently depend on a few existing copy markers, implementation should follow this rule:

```text
Keep old smoke marker strings in non-visible constants.
Change visible UI copy to the field-language version.
Run v39 Smoke after each small batch.
```

Recommended implementation batches:

```text
Batch 1: Steps 5-6
Batch 2: Steps 7-8
Batch 3: Steps 9-10
Batch 4: Steps 11-13
Batch 5: QA documents and demo memo wording
```

## 6. Copy review checklist

Before demo freeze, check every v39 screen against the following questions.

```text
Would a Korean team leader understand this without explanation?
Would this sentence sound natural in a leadership workshop?
Is this phrased like a business situation, not a software feature?
Does it avoid scoring, grading, or evaluation pressure?
Does it keep the leader responsible for judgment?
Does it avoid asking for real field-sensitive information?
Does it sound like a colleague wrote it, not like a machine generated it?
```
