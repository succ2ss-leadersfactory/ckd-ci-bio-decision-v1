
```text
- v39 Smoke 또는 readiness audit failure
- 보호 파일 변경 발견
- 고객 시연 화면에 preview/v39/internal 문구 노출
- 실제 고객명·병원명·의료진명·제품명·내부 수치 입력 요구 문구 발견
```
