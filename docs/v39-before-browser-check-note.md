# v39 브라우저 확인 전 마지막 메모

## 현재 상태

v39는 5단계부터 13단계까지 UX wrapper와 현장언어 1차 교정을 마친 상태다.

최근 확인 커밋 `ea5672dba98a2e23d691ac2177e4a0c760d5c5d1` 기준으로 아래 자동 검증이 모두 통과했다.

- C1Bio MVP CI
- v35 Smoke
- v36 Smoke
- v38 Smoke
- v39 Smoke

## 브라우저에서 볼 것

- 5단계에서 13단계까지 이동이 자연스러운가
- 앞 단계에서 남긴 메모가 다음 화면 상단에 보이는가
- 문장이 교육장 현장언어처럼 읽히는가
- 점수표나 평가표처럼 보이지 않는가
- PC, 태블릿, 모바일 화면이 무너지지 않는가
- 복사, 다시 불러오기, 초안 채우기 버튼이 작동하는가
- 브라우저 콘솔에 치명 오류가 없는가

## 확인 순서

1. `/journey-v39-preview.html`을 연다.
2. `docs/v39-phase1-localstorage-qa-seed.md`의 스크립트를 Console에 붙여 넣는다.
3. 화면을 새로고침한다.
4. 5단계부터 13단계까지 이동하며 상단 상태 카드를 본다.
5. 결과를 `docs/v39-phase1-manual-qa-execution-sheet.md`에 남긴다.

## 판단

브라우저 확인에서 큰 문제가 없으면 v39를 시연 후보로 동결한다.

문구, 배치, 연결, 콘솔 오류 중 하나라도 걸리면 v39 preview 안에서만 고친 뒤 다시 CI와 브라우저 확인을 진행한다.
