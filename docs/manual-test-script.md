# C1바이오 AI 리더십 Lab 수동 테스트 스크립트

이 문서는 Vercel 재배포 후 강사 또는 운영자가 실제 교육장과 동일한 흐름으로 앱을 점검하기 위한 수동 테스트 스크립트입니다.

## 0. 테스트 준비

- 브라우저: Chrome 권장
- 테스트 기기: 강사용 노트북 1대, 참여자용 노트북 또는 태블릿 1대
- 테스트 세션코드: `C1BIO-1차`
- 테스트 이름: `QA테스터`
- 테스트 팀명: `테스트조`

## 1. 참여자 앱 접속 테스트

1. Vercel Production URL을 연다.
2. `/` 경로에서 입장 화면이 보이는지 확인한다.
3. 세션코드, 이름, 팀명을 입력한다.
4. `저장하고 다음`을 누른다.
5. 화면 하단 저장 상태가 표시되는지 확인한다.

정상 기준:

- 과정명이 보인다.
- CP 안내 문구가 보인다.
- 다음 화면으로 이동한다.
- 새로고침 후에도 입력값이 유지된다.

## 2. AI 안전선 카드 테스트

1. AI 안전선 카드 화면으로 이동한다.
2. 각 카드에서 분류 버튼을 눌러본다.
3. 정답 문구가 표시되는지 확인한다.
4. 강사용 대시보드에서 응답 JSON에 안전선 응답이 들어갔는지 확인한다.

정상 기준:

- 카드 선택이 가능하다.
- 선택 후 화면이 깨지지 않는다.
- localStorage 응답에 `safety` 관련 데이터가 남는다.

## 3. 좋은 질문 만들기 테스트

1. 좋은 질문 만들기 화면으로 이동한다.
2. 기본 프롬프트를 일부 수정한다.
3. `프롬프트 복사` 버튼을 누른다.
4. 메모장이나 AI 도구 입력창에 붙여넣어 복사가 되었는지 확인한다.

정상 기준:

- 프롬프트가 복사된다.
- 저장 상태가 표시된다.
- 실제 고객명·제품명 입력 금지 안내가 계속 보인다.

## 4. Dashboard Lab 테스트

1. MR 활동·성과 Dashboard Lab 화면으로 이동한다.
2. 6명의 팀원 카드가 보이는지 확인한다.
3. 고객군 A~D 카드가 보이는지 확인한다.
4. `우선 확인 팀원`, `핵심 신호 3개`, `Gap 원인 가설`, `확인 질문`을 입력한다.
5. 저장한다.

정상 기준:

- 신재영 대리, 이대은 대리, 박재욱 사원, 유희관 과장, 김문호 차장, 김재호 차장이 보인다.
- 고객군 A~D가 보인다.
- 저장 후 강사용 대시보드에서 응답 확인이 가능하다.

## 5. 성과대화 프롬프트 & AI 답변 감별 테스트

1. 대상 팀원을 선택한다.
2. 자동 생성 프롬프트가 표시되는지 확인한다.
3. `복사` 버튼을 누른다.
4. 외부 AI에 붙여넣는다고 가정하고 샘플 답변을 작성해 붙여넣는다.
5. 감별 체크리스트를 체크한다.
6. 그대로 쓸 문장, 수정할 문장, 위험 문장, 현장 언어 수정문을 입력한다.
7. 저장한다.

정상 기준:

- AI 답변 원문이 저장된다.
- 감별 기준 8개가 보인다.
- 최종 수정문이 저장된다.

## 6. MR 1on1 코칭 Lab 테스트

1. 페르소나를 선택한다.
2. AI 프롬프트를 복사한다.
3. 대화 목적, 대화 시작 문장, 코칭 질문, 피해야 할 표현, 다음 1주 행동 약속, 팀장 지원 문장을 입력한다.
4. 저장한다.

정상 기준:

- 성과 이름 + 직급으로 인물명이 표시된다.
- 이름만 단독으로 표시되지 않는다.
- 1on1 대화 결과가 강사용 화면에서 확인된다.

## 7. 실행계획 & 결과 요약 테스트

1. 실행계획 화면으로 이동한다.
2. 7일 실행계획, 30일 점검 기준, 이해관계자 조율 행동, 고객 접점 품질 개선 행동, AI 활용 팀장 원칙을 입력한다.
3. 전체 결과 복사를 누른다.
4. 메모장에 붙여넣어 요약 내용이 복사되었는지 확인한다.

정상 기준:

- 전체 결과 요약이 표시된다.
- 복사가 가능하다.
- 민감정보 입력 금지 안내가 보인다.

## 8. 강사용 대시보드 테스트

1. `/?view=instructor`로 이동한다.
2. 전체 응답 화면 수가 보이는지 확인한다.
3. pendingSync 건수가 보이는지 확인한다.
4. 참여자 응답 JSON이 표시되는지 확인한다.

정상 기준:

- 강사용 화면이 열린다.
- 평가 점수, 등급, 순위가 없다.
- 토의 지원용 데이터만 보인다.

## 9. 사전점검 화면 테스트

1. `/?view=check`로 이동한다.
2. Google Script URL 설정 여부를 확인한다.
3. 아래 순서대로 버튼을 누른다.
   - `ping`
   - `setupSheetsC1Bio`
   - `saveParticipant`
   - `saveResponse`
   - `getDashboardData`
4. Google Sheets에서 Participants, Responses에 테스트 행이 생겼는지 확인한다.

정상 기준:

- 모든 테스트가 `✅ 성공`으로 표시된다.
- Google Sheets에 테스트 행이 생긴다.
- 실패 시 오류 메시지가 화면에 표시된다.

## 10. 실패 시 대응

| 증상 | 1차 확인 | 조치 |
|---|---|---|
| Google Script URL 미설정 | Vercel 환경변수 | `VITE_GOOGLE_SCRIPT_WEBAPP_URL` 등록 후 Redeploy |
| ping 실패 | Apps Script Web App URL | `/exec` URL인지 확인 |
| saveResponse 실패 | Apps Script 권한 | 웹 앱 액세스 권한을 모든 사용자 또는 링크 사용자로 설정 |
| Sheets에 행이 안 생김 | setup 실행 여부 | `setupSheetsC1Bio` 재실행 |
| 새로고침 후 값 사라짐 | 브라우저 localStorage | 시크릿 모드 여부 확인 |
| 참여자 화면이 안 열림 | Vercel 배포 | Deployments에서 최신 배포 상태 확인 |
